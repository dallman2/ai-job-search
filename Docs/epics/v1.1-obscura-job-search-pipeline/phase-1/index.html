Phase 1: Search Coverage Expansion

Epic: v1.1-obscura-job-search-pipeline Phase: 1 Depends on: Phase 0 (Pipeline Construction)

Phase Objective

Fix the search coverage gap exposed by the Phase 0 smoke test: only 1 of 5 search strategies worked (direct Greenhouse navigation). Google (site: queries) was blocked by CAPTCHA. Wellfound returned a login wall. YC Jobs returned noisy/unfiltered results. LinkedIn was unreachable without auth. Build two supplementary search paths — a curated direct board list (no auth, 100% reliable) and cookie-based authentication for gated boards (LinkedIn, Wellfound) — so the pipeline covers all target companies without depending on Google discovery.
