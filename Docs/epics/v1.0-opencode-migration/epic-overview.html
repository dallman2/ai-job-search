Epic Overview: v1.0-opencode-migration

Epic Vision

Transform the ai-job-search repo from a Claude Code procedural-recipe architecture into an opencode-native, goal-oriented skills architecture. Remove every model-specific idiom so the system works for any OpenAI-compliant tool-calling model without the model ever needing to know it was built for Claude.

The core directive: content stays, orchestration is rewritten. Evaluation frameworks, writing rules, LaTeX templates, CLI tools, and profile data are all model-agnostic and remain intact. The 5 procedural command files (~1,100 lines of Claude Code slash commands) are replaced by 4 goal-oriented skills (~280 lines total) plus 2 subagent definitions in opencode.json.

Success means a user opens the repo in opencode, says "evaluate this job posting" or "search for jobs in Copenhagen," and the system works — with the model reasoning dynamically about execution order rather than following a script.

Conventions

  1. Skill files are goal-oriented: begin with "Your purpose is to..." or "Your goal is," never "Follow these steps exactly in order"
  2. Never micromanage context: no "do not re-read," "you already have X," or "hold this in context" directives
  3. Subagents are defined in opencode.json with persistent system prompts, never constructed ad-hoc by the main model
  4. All tool references use opencode names: Task (not Agent), Question (not AskUserQuestion), WebFetch (not WebSearch)
  5. AI tooling references in CVs/cover letters use "opencode" (not "Claude Code")
  6. All file paths in data-files attributes are relative to repo root
  7. Every sprint plan follows this template: <article data-doc-type="sprint-plan"> with #objective, #rationale, #scope (in/out), #execution-plan (task groups), #tech-stack, #verification, breadcrumb <nav>
  8. The verification checklist from the original CLAUDE.md (factual accuracy, targeting, consistency, quality, compiled PDF) is preserved — it is content, not Claude-specific orchestration

Acceptance Criteria

  • .claude/ directory no longer exists
  • Zero occurrences of "follow these steps exactly in order" in any instruction file
  • Zero occurrences of $ARGUMENTS in any instruction file
  • Zero occurrences of allowed-tools in any skill file
  • Zero occurrences of WebSearch in any instruction file
  • Zero occurrences of "Claude" as an actor (not historical reference) in instruction files
  • opencode.json is valid and registers all 7 skills + 2 subagents
  • All 4 new skills are goal-oriented (<100 lines each) and dispatch correctly
  • Reviewer subagent is defined in opencode.json (not inline)
  • End-to-end test: URL job posting → compiled 2-page CV + 1-page cover letter
  • End-to-end test: pasted job description → compiled PDFs
  • End-to-end test: Danish-language posting → Danish cover letter
  • README.md updated with opencode instructions
