Sprint 0: Repository Restructuring

Phase: 0 Sprint: 0 Depends on: —

Objective

Physically reorganize the directory structure from Claude Code conventions to opencode conventions. Rename CLAUDE.md. Move .claude/skills/ and .claude/agents/ into .opencode/. Delete .claude/commands/ and .claude/settings.local.json. Update all internal path references. Zero logic changes.

Rationale & Context

opencode uses .opencode/ for skills, agents, and instructions. .claude/ is a Claude Code convention that opencode ignores. The existing .agents/skills/ job portal CLI tools are already compatible with opencode (they appear in the available_skills list) and stay in place. The CLAUDE.md file name is Claude-branded and should be renamed.

This sprint is deliberately zero-logic-change: only mv, rm, mkdir, and path-reference updates. Any content modification is deferred to Sprint 1. This makes rollback trivial and isolates content changes from structural changes.

Before touching any file, the entire sprint must be validated against caroline's .opencode/ directory structure to ensure opencode compatibility.

Scope

In-Scope

  • Create .opencode/ directory with skills/ and agents/ subdirectories
  • Move .claude/skills/job-application-assistant/ → .opencode/skills/job-application-assistant/ (7 files)
  • Move .claude/skills/job-scraper/ → .opencode/skills/job-scraper/ (2 files)
  • Move .claude/skills/upskill/ → .opencode/skills/upskill/ (1 file)
  • Move .claude/agents/gemini-research-expert.md → .opencode/agents/gemini-research-expert.md
  • Rename CLAUDE.md → OPENDOC.md
  • Delete .claude/commands/ (4 markdown files: apply.md, setup.md, expand.md, reset.md)
  • Delete .claude/settings.local.json
  • Delete empty .claude/ directory
  • Update all relative path references in skill files from .claude/skills/ → .opencode/skills/
  • Update all relative path references in CLI skill files for bun run commands if affected

Out-of-Scope

  • Modifying any file content beyond path-reference updates
  • Moving or modifying .agents/skills/ (already opencode-compatible)
  • Creating opencode.json (Sprint 2)
  • Updating README.md or SETUP.md (Phase 2 Sprint 3)

Execution Plan

1. Validation: Study opencode Conventions

  1. Task 0.1: Verify opencode directory conventions against caroline

    Read caroline's .opencode/ directory structure. Confirm: (a) skills live in .opencode/skills/<name>/SKILL.md, (b) agents live in .opencode/agents/, (c) opencode recognizes .agents/skills/ as a valid skill location. Document any differences from the proposed structure before making changes.

2. Create Target Directory Structure

  1. Task 0.2: Create .opencode/ directory tree

    mkdir -p .opencode/skills .opencode/agents. Verify creation.

3. Move Skill Files

  1. Task 0.3: Move job-application-assistant skill

    mv .claude/skills/job-application-assistant .opencode/skills/job-application-assistant. 7 files: SKILL.md, 01-candidate-profile.md through 07-interview-prep.md.

  2. Task 0.4: Move job-scraper skill

    mv .claude/skills/job-scraper .opencode/skills/job-scraper. 2 files: SKILL.md, search-queries.md.

  3. Task 0.5: Move upskill skill

    mv .claude/skills/upskill .opencode/skills/upskill. 1 file: SKILL.md.

4. Move Agent File

  1. Task 0.6: Move research expert agent

    mv .claude/agents/gemini-research-expert.md .opencode/agents/gemini-research-expert.md. Note: this file will be rewritten in Phase 1 to remove Claude Code format.

5. Rename Main Instruction File

  1. Task 0.7: Rename CLAUDE.md to OPENDOC.md

    mv CLAUDE.md OPENDOC.md. Content unchanged at this stage. The file retains the full candidate profile template and workflow rules; stripping happens in Sprint 1.

6. Delete Claude Code Artifacts

  1. Task 0.8: Delete commands directory

    rm -rf .claude/commands. Removes apply.md, setup.md, expand.md, reset.md. These 4 files (~1,100 lines) will be re-expressed as opencode skills in Phase 1.

  2. Task 0.9: Delete settings file and empty .claude/

    rm .claude/settings.local.json then rmdir .claude. If .claude/ still contains files, investigate before force-deleting.

7. Update Internal Path References

  1. Task 0.10: Update .claude/ path references in skill files

    Grep for .claude/skills/ across all moved skill files and CLI skill files. Replace with .opencode/skills/. Files likely affected: SKILL.md files that reference profile files (e.g., "Read .claude/skills/job-application-assistant/01-candidate-profile.md" → ".opencode/skills/job-application-assistant/01-candidate-profile.md"). Also check OPENDOC.md for path references to the repo structure section.

  2. Task 0.11: Verify bun run paths in CLI skills still resolve

    CLI skills reference paths like skills/jobindex-search/cli/src/cli.ts. Since these skills live in .agents/skills/, the bun run commands use paths relative to repo root (e.g., bun run .agents/skills/jobindex-search/cli/src/cli.ts search). Verify these paths still resolve after the move of sibling directories. They should be unaffected since .agents/ didn't move, but confirm.
