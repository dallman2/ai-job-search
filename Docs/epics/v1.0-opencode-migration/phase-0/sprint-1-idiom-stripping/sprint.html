Sprint 1: Idiom Stripping

Phase: 0 Sprint: 1 Depends on: Sprint 0

Objective

Edit every instruction file to remove all six categories of Claude Code idiom. After this sprint, the repo content is model-agnostic instruction language: no Claude branding, no procedural step-rigidity, no manual context management, no $ARGUMENTS, no allowed-tools frontmatter, no WebSearch. The actual workflow logic remains intact — only how it's expressed changes.

Rationale & Context

Six Claude Code idioms are embedded across ~20 instruction files. Each must be systematically removed:

  1. Manual context management (~15 occurrences): "Do not re-read," "You already have X in context from Step 1," "Hold this content throughout." OpenAI models manage their own context. These instructions cause second-guessing and degrade reasoning.
  2. Step-rigid directives: "Follow these steps exactly in order," "Do not skip steps," "Never skip this step." OpenAI models reason dynamically. Procedural scripts over-constrain them.
  3. $ARGUMENTS variable: Claude Code's slash-command variable injection. opencode has no equivalent. Models extract intent from conversation naturally.
  4. Claude branding: "Claude acts as," "a second Claude agent," "mention Claude Code by name." Replace with model-agnostic language.
  5. allowed-tools frontmatter: Claude Code skill metadata. opencode manages permissions in opencode.json.
  6. context: fork directive: Claude Code sandboxing feature. Not needed in opencode.

The files being edited were moved in Sprint 0 and are now at their final locations. The content of profile files (01-07) and LaTeX guides (05, 06) is model-agnostic domain knowledge and remains structurally unchanged beyond removing Claude-specific references.

Scope

In-Scope

  • Strip manual context management from skill files, OPENDOC.md, and agent files
  • Remove all "exactly in order" and "do not skip" directives
  • Remove all $ARGUMENTS references and conditional logic based on them
  • Replace "Claude" / "Claude Code" with model-agnostic language or "opencode" where appropriate
  • Remove allowed-tools lines from all SKILL.md frontmatter blocks
  • Remove context: fork from .agents/skills/ SKILL.md files
  • Remove "Token-efficiency rules" sections entirely
  • Remove "spawn a Claude agent" / "second Claude agent" → "subagent" or "reviewer agent"
  • Update "Agentic coding references mention Claude Code by name" → "mention opencode by name"
  • Update SETUP.md installation instructions from Claude Code to opencode

Out-of-Scope

  • Rewriting skills into goal-oriented format (Phase 1)
  • Changing evaluation frameworks, writing rules, or template guides (they are domain content)
  • Modifying LaTeX templates
  • Rewriting the reviewer agent (Phase 1 Sprint 4)
  • Creating the actual reviewer subagent prompt (this sprint only strips old idioms; the new content comes in Phase 1)
